No verified production private storage, V3.2 isolated adapter only. ## Simulation and reconciliation
Separate test-only module never imported by production route. Exact fixture-only IDs/scope, reserved fixture.invalid URL, bound simulated file size/hash/revision, fresh fixture manifest (15 min), purpose-bound test delivery grant; no external callbacks/network. Pure request and readback descriptor, no HTTP adapter. WeakMap-issued immutable plans, session-local synchronous reservation before response (MAYBE_SUBMITTED); content/type/languages/purpose/account/environment key (not title/ID/revision) prevents duplicate upload even across same-content documents. Binding hash includes all IDs, revisions, scope, association, nickname, validity, manifest. Changed content/type/languages new key but unresolved previous operation for same doc/account/environment blocks. In-memory only, bounded 100 operations, no Redis writes, no cross-process persistence or restart recovery claim. Unknown lost response retains reservation; no external ID means no status request or recovery search. Only known fixture ID + exact scope/operation binding allows GET descriptor. 201 must contain SUBMITTED and matching fixture ID/location/type/languages; GET requires 200 and matching exact fixture ID/type/language set, optional metadata checked against PDF bytes size/type, numeric error/warning codes; stale/future/conflicting observations fail closed. 404 does not release reservation. Processing/accepted/rejected only fixture statuses; preserve terminal status and reference on contradiction. Document/file/review/scope/association changes, expiry/archive mark historical reference superseded or unresolved (no automatic release); accepted old revision never valid for new revision. Content/type/languages changes require new media review; title or association changes require re-association review, no automatic new upload or reuse. No deletion.
