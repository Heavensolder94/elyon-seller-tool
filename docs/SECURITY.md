# Security

## Sicherheitsprinzipien

- Bestehende Schutzmechanismen nicht umgehen.
- Neue Funktionen sicher ergänzen.
- Rollen und Rechte klar trennen.
- Sensible Daten nicht öffentlich speichern.

## Sicherheitsbereiche

- Sandbox-Modus
- Sicherheitsmodus
- Rollenrechte
- API-Schutz
- lokale Datenspeicherung

## Empfehlungen

- API-Keys nur über ENV-Variablen speichern.
- Kritische Funktionen absichern.
- Änderungen defensiv umsetzen.
