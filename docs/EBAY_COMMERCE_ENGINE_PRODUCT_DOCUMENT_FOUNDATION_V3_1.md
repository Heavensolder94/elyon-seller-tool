No automatic conversion of business docs; reverse overwrite blocked. Versioned productDocument schema elyon-product-document-v3.1, server document timestamps and version, archive/restore existing CAS plus exact per-document version on product actions. Metadata can be incomplete. GPSR compliant false; no document ID injected in existing GPSR. Existing Company GPSR API merges manufacturer/responsiblePerson and regulatoryDocumentIds; Nova GPSR cache has manufacturer/responsiblePerson. No new GPSR engine or changes to productive paths.
