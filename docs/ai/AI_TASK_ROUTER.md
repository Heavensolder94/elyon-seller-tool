# AI Task Router

## Zweck

Diese Datei beschreibt, welche Aufgaben an welche Agenten weitergeleitet werden.

## Routing

### Soul Scout

- Produktideen
- Chancenbewertung
- Nachfrageprüfung

### Soul SEO

- eBay-Titel
- Keywords
- Beschreibungen
- SEO-Optimierung

### Soul Guard

- Risikoanalyse
- Sicherheitsprüfung
- Compliance-Hinweise

### Soul Finance

- Gewinnanalyse
- Gebühren
- Cashflow

### Soul Support

- Kundennachrichten
- Retourenkommunikation
- Supporttexte

### Soul Operations

- Tagesfokus
- Aufgabenstruktur
- operative Hinweise

## Regeln

- Sicherheitslogik immer beachten.
- Keine autonomen Live-Aktionen ohne Freigabe.
