## Architecture
Existing V2.1 Product Board panel imports a lazy review module and pure local suggestion helper. In-memory selection up to 50 rows, no writes or persistence, input editing invalidates prior result. Explicit single/batch review invokes Seller Tool POST /api/price-stock-preview (existing requireSellerAccess and body limit), forwards only narrow target and desired/current-observation fields via HTTPS and existing server-side sync code to Company OS POST /api/price-stock-preview. No browser secret. Company OS uses assertCompanyOsSyncCode, canonical state, existing auto-lister snapshot and readEconomicsSettings once per request. No additional eBay or supplier requests. No per-keystroke requests. Two additional function routes justified by server-only canonical engine and seller authentication. Existing sync secret is shared access, not proof of individual actor/account/workspace association. No new dependency, database, cron, AI or polling.
## Price / stock
Reuse product-economics-core.js evaluateProductEconomics({canonical product}, workspace rules, {previewPrice,now}) and evaluateListingEconomics for saved price gate. Preview is always nonbinding. Existing assessEconomicMinimum uses profit OR margin, no duplicate rules. Existing tax, fees, reserve, shipping and completeness logic retained. Current observations from browser explicitly unverified; stored canonical baseline vs hypothetical preview, fees/profit/margin and rule revision returned. No market-price invention, no automatic decrease after cheaper purchase. Local suggestions compare saved parent price only for nonvariant row, mark missing/stale facts. Existing Seller Tool evaluateStockGuard is a publication guard, not a revision authorization rule; do not apply its zero-publication blocker to reductions. V2.2 permits local reduction up to recent observed supplier quantity, no increase even manually (deferred verified stock/limit contract); unknown and stale values block stock proposal. No authoritative historic purchase/fee change detection yet. Variant-specific preview uses variantEconomicsFacts and saved gate variantOffers, never parent offeredPrice. Missing variant facts block numeric calculation. Variant CSV relationship syntax unverified: all variant exports blocked.
